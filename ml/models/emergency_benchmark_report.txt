1. OBJECTIVE & EXPERIMENTAL SETUP:
   - Task        : Binary Emergency Detection (0 = non-emergency, 1 = emergency)
   - Input       : Cleaned text messages from train.csv (20,749) and test.csv (5,196)
   - Pipeline    : text -> TfidfVectorizer(max_features=15000, ngram_range=(1,2)) -> LogisticRegression
   - Models Tested:
     * Experiment A: class_weight=None (Baseline, preserves original class prior)
     * Experiment B: class_weight='balanced' (Inversely proportional to class frequencies)
   - Scope Limitation:
     * This model strictly detects binary emergency occurrence.
     * It does NOT estimate emergency severity.
     * It does NOT perform multi-label agency/disaster categorization.
     * Threshold calibration does NOT guarantee operational or clinical infallibility;
       it illustrates the precision/recall trade-off for emergency dispatch operations.
